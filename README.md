# 🔬 Chem Microscope · 初中化学宏微观三层穿透显微镜

> 基于原生 HTML5 Canvas 的初中化学可视化显微镜。零外部依赖、零构建步骤、零后端 —— 双击 `index.html` 即用。
>
> 拖动时间轴，在 **L1 宏观 / L2 分子 / L3 原子** 三层视界之间自由穿透，看清化学反应的真相。

## 项目简介

把课本上"记结论"的化学方程式，变成一台可以推着时间轴逐帧观察的显微镜：

- **宏观**看得见现象（燃烧、气泡、沉淀），
- **分子**看得见碰撞与断键成键，
- **原子**看得见电子转移与重组。

纯 HTML5 + CSS + 原生 JavaScript + Canvas 实现，无框架、无 npm、无网络请求。适合课堂演示、自学探究与二次开发。

## 核心特性

| 特性 | 说明 |
| --- | --- |
| **三层穿透视界** | L1 宏观实验台 / L2 分子碰撞断键 / L3 原子重组与电子转移，任意层同步演变 |
| **实时连续时间轴** | 0% → 100% 连续推演，支持一键自动播放（约 10s 匀速）与阶段标签跳转定格 |
| **旁观粒子弱化聚焦** | 「🎯 聚焦反应实质」开关：旁观离子透明度降至 0.22，一眼锁定真正断键/成键的粒子 |
| **五层防遮挡渲染管线** | 背景网格 → 键连线 → 原子球体 → 电子轨道/电子点 → 标签胶囊顶层；安全净空区 + 标签防碰撞合并，结构性零遮挡 |
| **插卡式反应卡带** | `engine.js` 引擎与 `data/*.js` 数据解耦，`window.CHEM_CARTRIDGES` 标准化注册表，新反应像插卡带一样扩展 |
| **移动端友好** | `<820px` 窄屏自动切换浮动目录抽屉 + 大触控热区，手机端体验完整 |

## 内置 14 个经典化学反应

按化合 / 分解 / 置换 / 复分解分类，覆盖初中化学核心反应类型：

### 化合反应（4）

| 反应 | 方程式 |
| --- | --- |
| 氢气燃烧生成水 | 2H₂ + O₂ →点燃→ 2H₂O |
| 碳在氧气中充分燃烧 | C + O₂ →点燃→ CO₂ |
| 镁条在空气中燃烧 | 2Mg + O₂ →点燃→ 2MgO |
| 铁丝在氧气中剧烈燃烧 | 3Fe + 2O₂ →点燃→ Fe₃O₄ |

### 分解反应（2）

| 反应 | 方程式 |
| --- | --- |
| 水的电解 | 2H₂O →通电→ 2H₂↑ + O₂↑ |
| 过氧化氢催化分解制氧气 | 2H₂O₂ →MnO₂催化→ 2H₂O + O₂↑ |

### 置换反应（2）

| 反应 | 方程式 |
| --- | --- |
| 铁与稀盐酸反应 | Fe + 2HCl = FeCl₂ + H₂↑ |
| 铁钉与硫酸铜溶液（湿法炼铜） | Fe + CuSO₄ = FeSO₄ + Cu |

### 复分解反应（5）

| 反应 | 方程式 |
| --- | --- |
| 大理石与稀盐酸制二氧化碳 | CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑ |
| 酸碱中和反应 | NaOH + HCl = NaCl + H₂O |
| 碱与盐生成蓝色沉淀 | 2NaOH + CuSO₄ = Cu(OH)₂↓ + Na₂SO₄ |
| 硫酸根离子的特征检验 | BaCl₂ + Na₂SO₄ = BaSO₄↓ + 2NaCl |
| 碳酸盐与酸的快速产气 | Na₂CO₃ + 2HCl = 2NaCl + H₂O + CO₂↑ |

### 其他 · 氧化还原（1）

| 反应 | 方程式 |
| --- | --- |
| 一氧化碳还原氧化铁（高炉炼铁） | 3CO + Fe₂O₃ →高温→ 2Fe + 3CO₂ |

## 快速开始

```bash
# 方式一：直接双击 index.html（推荐）
# 方式二：任意静态服务器
python -m http.server 8000   # 或 npx serve
```

> 纯 `file://` 协议即可运行，无需任何安装。

## 项目结构

```
chem-microscope/
├── index.html                     # 页面骨架（双击即入口）
├── style.css                      # 全部样式（含移动端响应式）
├── engine.js                      # 渲染引擎：三层视界 + 时间轴 + UI 绑定
├── data/
│   ├── ch1_water.js               # 第1章 · 水
│   ├── ch2_oxygen_carbon.js       # 第2章 · 氧气与碳
│   ├── ch3_metals.js              # 第3章 · 金属与氧化还原
│   └── ch4_acids_bases_salts.js   # 第4章 · 酸碱盐与复分解
└── tools/
    └── validate_cartridges.js     # 卡带 Schema 静态校验器
```

## 二次开发：像插卡带一样加反应

1. 在 `data/` 下的卡带文件中按 Schema 注册一条反应（坐标 / 时序 / 断键成键点 / 解说文案）；
2. 运行 `node tools/validate_cartridges.js` 静态校验（坐标、时序、色标、解说完整性）；
3. 刷新页面，目录栏自动出现新卡带 —— 引擎零改动。

```bash
node --check engine.js && node tools/validate_cartridges.js
```
